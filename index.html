配音服务

本地语音直接使用 Windows 已有的中文 / 英文声音，不安装系统组件。若缺少对应语言声音，可切换语音 API。语音服务与生成代码的模型分别配置。

接口需支持 POST /audio/speech，接收 model、input、voice、speed、response_format=wav 并返回音频。确认声音支持所选语言；沿用下方 HTTP 代理和超时设置。

高级设置
单次输出预算

输出预算可继续调高，实际支持范围由模型和服务商决定。模型单次上限填 0 时不预先限制；仅在服务商明确返回上限时自动适配。输出截断会有限次数续写，仍未完成则保留部分内容。续写会增加调用次数和费用，设为 0 可关闭。推理 Token 也可能计入预算；长输出可相应调高响应超时。
